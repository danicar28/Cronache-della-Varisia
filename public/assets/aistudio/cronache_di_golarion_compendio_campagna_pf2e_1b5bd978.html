Configurazione Cloud Condiviso & AI (GitHub / PC)

Come collegare un database condiviso gratuito su GitHub Pages:

1. Chiave Gemini AI: Vai su Google AI Studio, crea una API Key gratuita e incollala qui sotto.

2. Database Condiviso (Firebase): Crea un progetto gratuito su Firebase Console, attiva Authentication (Anonima) e Firestore Database, registra una Web App e incolla l'oggetto firebaseConfig JSON qui sotto.

Nota: se apri il file direttamente dal PC (file://), Firebase blocca per sicurezza l'autenticazione e l'app usa automaticamente la modalità Locale. Su GitHub Pages (https://) si connetterà al Cloud.

Vuoi esportare una copia del file HTML con queste chiavi già salvate dentro (così i tuoi compagni su GitHub non dovranno inserirle)?
